# Decisions log

One line per decision, gotcha, or deviation from the spec. Newest at the bottom.

- 2026-09-20: Repo name assumed `AA-BuildingBlocks` (GitHub does not allow spaces); `base` is `/AA-BuildingBlocks/` in vite.config.js.
- 2026-09-20: Pinned deps: three 0.186.0, vite 8.3.0, gsap 3.15.0, idb-keyval 6.3.0, vite-plugin-pwa 1.3.0, @fontsource/pixelify-sans 5.3.0.
- 2026-09-20: Font is Pixelify Sans (OFL-1.1) bundled via @fontsource (latin 400/700 only); fallback stack is Nunito / ui-rounded / system-ui.
- 2026-09-20: PWA icons are generated by `tools/make-icons.mjs` (a dependency-free PNG encoder over a 32x32 pixel-art drawing) and checked in under public/.
- 2026-09-20: Stage 1 boots straight into Profile 1 (Atharv) because the profile picker is Stage 4.
- 2026-09-20: Stage 1 includes a minimal "Tap to play" card (needed to unlock iOS audio) and place/break/tap/footstep sounds only; ambient/music wait for Stage 3.
- 2026-09-20: Atlas bleed: tiles are drawn at full 64 px and UVs are inset by 2 px; GPU mipmaps are box filters aligned to tile boundaries, so cross-tile bleeding only starts at mip level 3 (8 px tiles) where it is invisible.
- 2026-09-20: Leaves are opaque cubes (not cutout) for performance and richer AO; the cutout material is used by flowers, tufts, wheat and torches.
- 2026-09-20: No light propagation / sunlight columns: the world is open-air, so per-vertex AO + shadows carry the look. Torch point lights come in Stage 3.
- 2026-09-20: Meshing runs on the main thread (64 chunks at boot, then at most 2 dirty chunks per frame); a worker was not needed on desktop and is deferred until device profiling says otherwise.
- 2026-09-20: Chunk meshes are positioned at the chunk origin (vertices are chunk-local) so three.js sorts transparent chunk meshes sensibly.
- 2026-09-20: Water and glass share one transparent Lambert material with depthWrite on; water alpha (0.65) lives in the tile itself.
- 2026-09-20: Shadow camera is snapped to whole blocks around the player so shadow edges do not swim while walking.
- 2026-09-20: Antialias is on (MSAA is cheap on Apple tile-based GPUs); revisit if the iPad profile shows a cost.
- 2026-09-20: Targeting: the white outline follows the screen centre; a tap or long-press acts on the block under the finger (ray from the tap point) within 6 blocks of the eye.
- 2026-09-20: The fence collides as a full cube (kids can step over it) to keep physics simple.
- 2026-09-20: Save format v1: per-chunk diff arrays (Uint16 voxel index + Uint8 block id) plus seed, under idb-keyval key `bv:world`; `bv:meta` holds first-launch time and the storage-persist result.
- 2026-09-20: document-level touchstart/touchmove preventDefault is used to kill Safari double-tap zoom; HUD uses pointer events so it is unaffected. Stage 4 file input must be triggered from pointerup.
- 2026-09-20: Debug overlay text is 16 px (below the 18 px child-facing minimum) because it is a developer tool hidden behind a three-finger tap / F3.
- 2026-09-20: Desktop fallback: F3 toggles the debug overlay, F toggles fly, C toggles camera, Shift sprints (or descends in fly), wheel/1-6 change hotbar slot.
- 2026-09-20: three r186 removed PCFSoftShadowMap; using PCFShadowMap (the current soft PCF filter) instead.
- 2026-09-20: Default third-person pitch is -25° (not -15°) so the screen-centre target lands ~4.5 blocks ahead, inside the 6-block reach.
- 2026-09-20: Touch handler ignores pointerType "mouse" in move/up too: Chrome's mouse uses pointerId 1, which collided with synthetic touch ids during testing; on a real iPad touches and mouse never share ids, but the guard costs nothing.
- 2026-09-20: Lighting balance after screenshots: hemisphere 1.35 / sun 2.0 (was 1.05 / 2.3) so sun-shadowed tree sides do not read as near-black.
- 2026-09-20: Document-level touchmove preventDefault will also block scrolling inside future panels; Stage 3 inventory must opt scrollable elements out (stopPropagation) or use pointer-driven scrolling.
- 2026-09-20: Verified on desktop Chromium (not iPad): 60 fps at DPR 2 with shadows, ~115 draw calls, place/break/particles, autosave round-trip across reload, offline load from the service-worker cache with the server stopped, auto-step, jump height ~1.3, fly, first-person toggle, multi-touch dispatch with synthetic pointer events. Real iPad, Safari, touch hardware and Add-to-Home-Screen are UNTESTED.
- 2026-09-20: A temporary .claude/launch.json was used to run the dev/preview servers during testing and removed afterwards (not part of the project).
